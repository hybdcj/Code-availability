# Version Notes and Reproduction Limitations

1. **Use the corrected analysis definitions.** Historical scripts are retained for traceability and because later scripts extract their preparation expressions. Their presence does not mean all historical reports remain valid. F24 corrects screening confusion-matrix metrics and includes ties at the cutoff; the actual selected fraction may differ from the target fraction. BDSI comparisons must also use the F26 corrections.
2. **BDSI and Tu comparisons have different scopes.** F26 corrects BDSI scoring at age 65 and three-valued logic for missing conditions. The training transformations and parameters required by the original Tu 2026 model were not fully available. Historical Tu results therefore cannot be described as faithful reproduction or valid external validation of that model. The older exploratory branches in F07/F14/F19/F22 should not be used directly as formal conclusions.
3. **Internal performance and imputation intervals.** F29 corrects alignment between prediction rows and outcomes; script 29 already includes the corrected functions. F30 describes variation using empirical quantiles of performance across imputations, not Rubin-pooled 95% confidence intervals. Update historical outputs before using them.
4. **Do not interchange samples or denominators.** F32 treats available samples for the integer score and continuous model separately; the integer score does not additionally require complete ADL. The broader-population extension includes original development participants and is not uniformly independent validation. See F27 for analyses excluding development participants.
5. **Measurement definitions.** Interpret the 2018–2020 memory-measurement changes and fixed-threshold/equipercentile definitions alongside F31. Do not pool interpretations across different outcome definitions.
6. **Figure/table source code is not a final deliverable.** Scripts 31/32 produce historical exports. A manuscript audit identified the longitudinal sleep effect in Figure 2(b)/Table 2 as the effect per one-hour increase in sleep duration, not “sleep <6 h.” English translation preserves the recorded analyses and does not correct this historical scientific label or alter effect estimates. Correct that label when regenerating formal figures/tables. Check the cross-sectional categorical term in Figure 2(a) separately; do not replace both indiscriminately.
7. **Layout-product dependencies.** F34/F36 depend on existing outputs, table sources, and historical TIFF/layout caches that are not distributed here. Running these scripts alone therefore does not guarantee all final figures/tables. Manuscript figures use TIFF; tables retain Word/tabular formats. No blank or fabricated figure placeholders are supplied.
8. **Environment and reproduction scope.** The original analysis is a local Windows workflow with manual staging, dated derived files, and historical repair steps. The configuration tool replaces known paths; it does not obtain data authorization, verify variables, build every cache, or schedule all dependencies. No full statistical rerun was performed for this release. English reporting labels and paths must be kept consistent when preparing historical inputs; consult the compatibility mapping.
9. **Public distribution and licensing.** The author requested public distribution of this repository. Public visibility does not itself supply an open-source license. No license, DOI, author email, or publication details have been invented.
