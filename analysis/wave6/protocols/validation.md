# 冻结模型时间迁移验证方案（2026-11-14）

本文件为已核查资格及事件数、尚未计算性能时记录的方案之公开摘要；
不构成原研究的前瞻性注册。
连续模型与整数评分配对比较使用四个预测变量完整的经核验风险集。
四年主窗口42—54个月，1,188人；2021年4,041人及2023年672人分别报告。
敏感性分析：45—51个月（1,187人）、排除全部开发来源队列（1,059人）、
使用官方访谈月份恢复日期冲突记录。固定所有原模型与评分系数。
报告AUC及配对差、连续模型offset截距、联合校准斜率与Brier，以及固定整数风险分层。
按2018年社区有放回抽样2,000次，使用百分位区间；社区内成员按抽中次数赋权，
不使用调查权重。种子为20261114加样本ID指纹。
校准曲线在预测logit上使用df=4三次B样条，绘制第1—99百分位范围，
四年组给出逐点Bootstrap区间；十分位分箱不强行拆分同值。
本阶段四年截距更新expit(lp+alpha)在同一样本拟合并评价，仅为表观性能，
未作乐观度校正；后续2026-11-16内部校正见独立方案。
三/五年校准与Brier为跨历时诊断。学习次数、词表、生存、应答选择和日期代理
限制保留。不开展DCA、IPCW、新Z分数结局或全部系数重拟合。
