# 第六期事件审计方案（2026-11-14）

本文件为事件计数前记录的分析方案之公开摘要，不构成前瞻性研究注册。
使用经核验的质控数据及全精度冻结系数。基线记忆分数>4，随访记忆分数≤4；
拒答及死亡不计为事件。排除实际开发参与者，分别报告2021、2022、2023年。
42—54个月为四年目标窗口，45—51个月及排除全部开发来源队列为敏感性分析；
恢复日期冲突记录仅用于敏感性分析。不能将5,901人合称为四年风险集。
报告Wilson区间、2,000次社区Bootstrap事件比例区间，以及按随访状态分组的
冻结预测风险。社区Bootstrap随机种子为20261114加样本指纹。
本阶段不重拟合、不计算AUC、不构建Z分数结局，也不对死亡使用普通IPCW处理。
不同历时不能解释为同历时概率校准。原开发样本为4,441人、658例事件。
